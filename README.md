# Лабораторна робота №7

## Тема
Computer Vision та багатопотоковість у C++

## Опис програми
Програма зчитує відео з камери, відображає оригінальний кадр і кадр після обробки. Обробка виконується за допомогою OpenCV: зображення переводиться у відтінки сірого.

## Структура проєкту
- `include/CameraProvider.hpp` — клас для роботи з камерою.
- `include/FrameProcessor.hpp` — клас для обробки кадрів.
- `include/KeyProcessor.hpp` — клас для обробки натискань клавіш.
- `src/main.cpp` — головний файл програми.
- `CMakeLists.txt` — файл для збірки через CMake.
- `preinstall.sh` — скрипт встановлення залежностей.
- `build.sh` — скрипт збірки та запуску.

## Встановлення залежностей
```bash
bash preinstall.sh
```

## Збірка та запуск

```bash
bash build.sh
```

## Керування

Для виходу з програми натисніть `Esc`, `q` або `Q`.
